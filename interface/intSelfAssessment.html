Interface System — Self-Assessment

Interface System Design Project Interface System Design Project Criteria Navigation Model & System Coherence 20/20

The Navigation system is consistent and clearly structured across all pages and uses a persistent hamburger menu that ensures users can always move between pages without losing orientation. The combination of a homepage as a visual index and a navigation system creates a coherent and predictable interface model while the desktop-style icon layout also reinforces the system's consistency.

Hierarchy & Mobile-First Logic 19/20

I designed mobile first by prioritizing vertical layout, spacing, and readability, then expanded the same structure for desktop. Hierarchy is maintained through consistent headings, icon labels, and grouping of content. The hamburger menu is in the same corner consistently in both mobile and desktop versions.

Explain how hierarchy survives compression and expands across contexts. 15/15

Hierarchy survives compression and expansion across contexts through consistent layout and spacing. Content is compressed vertically on mobile but still clearly organized through headings and icon grouping. On desktop, the layout expands without breaking the original hierarchy system.

Theoretical Integration (Norman / Nielsen / Shneiderman) 15/15

I applied Norman's principles through signifiers using icons, labels, active states, feedback by changing headers and constraints using a hamburger menu-based navigation. Nielsen's heuristics appear through consistency, visibility of system status, and recognition over recall. Shneiderman's rules are reflected in consistency, user control, feedback, and reduced memory load.

Cross-Page Consistency 10/10

All pages follow the same navigation system, typography style, and interaction patterns. The hamburger menu, icon system, and layout logic remain consistent across homepage and all subpages, creating a unified interface system.

Risk & Structural Ambition 5/5

The design goal was to combine desktop OS-style layout with inspiration from Nintendo DS and early 2000s phone interfaces. This was successfully simplified into a functional, grayscale interface system focused on usability and structure rather than decoration.

Iterative Development 8/10

The evolution of the design is reflected in the progressive refinement of the navigation system and the consistency of the interface elements.

Participation & Critique Engagement 5/5

I attended all classes that were not asynch and spoke with my peers during break out rooms where we gave each other tips and critiques.
